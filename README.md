# landing-p3b
3310 Fairmount P3B landing page

Static "coming soon" page, deployed as an Azure Static Web App.

## Structure
- `index.html` — the page
- `css/styles.css` — styling
- `assets/images/` — put the background image here as `background.jpg`
- `assets/video/` — put project video files here
- `staticwebapp.config.json` — Azure Static Web Apps configuration

## Local preview
Open `index.html` directly in a browser, or serve the folder with any static file server.
